# Security policy

## Supported versions

Prumio has not been released yet. Once released, security fixes target the latest version.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private vulnerability
reporting: *Security → Report a vulnerability* on https://github.com/AlexandreZanata/Prumio.

Include the affected version, steps to reproduce and the impact. You will get an acknowledgment
within 7 days. Please allow time for a fix before public disclosure.

## Scope notes

Prumio has no network access and no server, so most risks concern local data: backup files
(plain or encrypted), the app's private database, exported calendar files, and intents/deep links
exposed by the app.
