# Internationalization

Supported languages: **English** (default, `values/`) and **Brazilian Portuguese** (`values-pt-rBR/`).
Every user-facing string exists in both, in the same change.

## Where strings live

| Kind | Location | Visibility |
|---|---|---|
| Generic actions (Save, Cancel, Close, Delete, Undo, Done, Back) | `core/ui/.../composeResources/values*/strings.xml` | public `Res` of `:core:ui` |
| Destination names (Today, Agenda, Matters, Inbox, Search, Settings) | same | public |
| Labels of model values (statuses, day periods, recurrence) | same, used through `:core:ui/label` functions | public |
| Feature-specific copy | `feature/<x>/src/commonMain/composeResources/values*/strings.xml` | internal `Res` |
| Notification texts (phase 4) | `core/notifications` composeResources | internal |
| App name only | `app/android/src/main/res/values/strings.xml` | Android resource |

Rules:
1. **Reuse before adding.** Search shared strings first; a string used by two modules moves to
   `:core:ui` (never duplicated).
2. Keys: `<feature>_<screen?>_<meaning>`, snake_case (`today_empty_title`). Shared:
   `action_*`, `destination_*`, `<model>_<value>` (`matter_status_waiting`).
3. No string concatenation for sentences; use format arguments (`%1$s`, `%1$d`) and plurals
   (`<plurals>`) for counts ("1 task" / "3 tasks").
4. Composables read strings with `stringResource(Res.string.x)`; non-UI code (notifications) uses
   the suspend `getString(Res.string.x)`.
5. Domain and data never produce user-facing text.
6. Compose resources are not Android resources: write `'` and `"` directly, never `\'` (🔒 `StringResourcesTest`, which also requires identical keys in both languages).

## Dates, times and numbers

- Formatting is localized and lives in `:core:ui/format` (expect/actual): `formatDayHeader`, and in
  phase 2 relative dates ("Today", "Tomorrow", "In 3 days"), times (12/24 h following the device),
  durations ("1 hour before").
- The first day of the week follows the locale unless the `week_start` setting overrides it.

## Language selection

Android 13+ per-app language is declared in `app/android/src/main/res/xml/locales_config.xml`.
Keep it in sync with the `values-*` folders. Settings links to the system screen.

## Adding a language (needs owner approval)

Add `values-<qualifier>/strings.xml` in every module with strings, the locale in
`locales_config.xml`, and a pseudo-locale screenshot check (phase 6, P6.12).

Recipe: [ai/recipes/add-string.md](../ai/recipes/add-string.md).
